# Stored learning graph

This read model projects persisted memory turns, tasks, policies, world models and skills. It reads the core-owned SQLite connection through deferred transactions; it does not call models, embed text, perform network requests or update records. Graphs describe saved learning and its recorded sources, not the model's pretrained knowledge.

The authenticated viewer exposes `GET /api/v1/brain/summary`, `/api/v1/brain/nodes` and `/api/v1/brain/edges`. Their response types live in [agent-contract/brain.ts](../../agent-contract/brain.ts). All accept the optional `ownerAgentKind`, `ownerProfileId` and `ownerWorkspaceId` filters. `ownerWorkspaceIsNull=1` selects records with no workspace and cannot be combined with `ownerWorkspaceId`; omitting both selects every workspace. The core API expresses these choices as `null`, a string, and `undefined`, respectively. Node requests select `kind`; evidence requests select an opaque `nodeId`. Each request retains the server's authentication and origin checks and returns `Cache-Control: no-store`.

Summary totals count every matching stored record, including archived records; `memory` counts grouped turns and `trace` counts their raw steps. A turn identity includes agent, profile, workspace, episode and turn number. Namespaces page in groups of 100 using `namespaceCursor`. Nodes and evidence use `cursor` and `limit` from 1 to 100. Follow every non-null continuation to reach all matching records. Cursors are bound to the requested category, source node and namespace filters.

Each node contains at most 4,000 characters of stored text, a truncation flag and a source reference for the existing detail view. Raw tool arguments, native model thinking and vector blobs are absent. A node page previews at most 12 outgoing evidence links per node; its evidence count and continuation expose the remainder. Links come only from recorded task membership, source arrays, policy trace links and world-model evidence IDs. An unresolved untyped evidence ID keeps type `unknown`; links never infer similarity from text or vectors.

An edge's `available` status means its target exists in storage; the viewer may not have loaded that target yet. `outside-filter` means it exists outside the selected namespace, and `missing` preserves a recorded reference whose target is absent. Source fields and original reference IDs remain available for inspection.

Each response is one consistent read, but multiple requests share no long-lived snapshot. Keyset order uses immutable identifiers, so deleting an earlier record does not skip later records. Concurrent insertion before the last cursor requires refreshing; `consistency: live` and response timestamps make that limitation explicit. Neither page limits nor graph rendering limits change the reported totals.
